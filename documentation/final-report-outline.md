# Final Report Structure — CSC1202

Use Trebuchet MS, 12 pt, 1.5 line spacing, justified alignment and IEEE referencing as required by the examination paper.

1. Title page and group/member details
2. Abstract / project summary
3. Chapter 1 — Introduction
   - Background and UCU context
   - Problem statement
   - Aim and objectives
   - Scope and significance
4. Chapter 2 — Requirements and analysis
   - Student and administrator needs
   - Functional requirements
   - Non-functional requirements
   - Acceptance criteria
5. Chapter 3 — System design
   - Proposed solution and workflows
   - Mobile and desktop wireframes
   - Use-case diagram
   - System architecture
   - ERD and database explanation
6. Chapter 4 — Implementation
   - Frontend React structure
   - Backend Node.js/Express routes and middleware
   - MySQL tables, keys and relationships
   - Authentication and authorization
   - Claim and confirmed-return business rules
7. Chapter 5 — Testing and results
   - Test environment and test matrix
   - Test steps, expected/actual outcomes and PASS/FAIL
   - Defects corrected and unresolved defects
   - Mobile and keyboard accessibility evaluation
8. Chapter 6 — Discussion, limitations and reflection
   - Design decisions
   - Challenges and resolutions
   - Individual contributions
   - Lessons learned and future improvements
9. Conclusion and recommendations
10. IEEE references
11. Appendices
   - Setup instructions
   - API summary
   - SQL schema and sample data description
   - Screenshots and milestone evidence
   - Contribution log

Do not write that a test passed unless it was actually executed and evidence was recorded.
